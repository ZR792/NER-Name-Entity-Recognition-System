# ── POSSIBLE ERRORS & SOLUTIONS ──────────────────────────────────────────────

ERROR 1 — ModuleNotFoundError: No module named 'spacy'
──────────────────────────────────────────────────────
Cause   : SpaCy not installed in active Python environment
Solution:
    py -3.11 -m pip install spacy==3.7.4 --prefer-binary

Check which Python notebook is using:
    import sys; print(sys.executable)
Make sure it matches where SpaCy is installed.


ERROR 2 — SpaCy 404 HTTP error during model download
──────────────────────────────────────────────────────
Cause   : Standard spacy download command fails in virtual environments
Solution: Use direct GitHub URL:
    py -3.11 -m pip install https://github.com/explosion/spacy-models/releases/download/en_core_web_sm-3.7.1/en_core_web_sm-3.7.1-py3-none-any.whl


ERROR 3 — Failed to build spacy (build errors on Windows)
──────────────────────────────────────────────────────────
Cause   : Python 3.14 is not supported by SpaCy 3.7.4
Solution: Install Python 3.11 and use it explicitly:
    py -3.11 -m pip install spacy==3.7.4 --prefer-binary
    
Do NOT use Python 3.14 for this project.


ERROR 4 — FileNotFoundError: cleaned_data.csv not found
──────────────────────────────────────────────────────
Cause   : Notebook 01 has not been run yet
Solution: Run notebooks in correct order — 01 must run before 02, 03, 04, 05


ERROR 5 — FileNotFoundError: NER_Dataset_Complete_Tagged.xlsx
──────────────────────────────────────────────────────────────
Cause   : Excel dataset not placed in data/ folder
Solution: Place NER_Dataset_Complete_Tagged.xlsx inside the data/ folder


ERROR 6 — ValueError: [E007] 'ner' already exists in pipeline
─────────────────────────────────────────────────────────────
Cause   : Trying to add NER pipe when it already exists in en_core_web_sm
Solution: Use get_pipe instead of add_pipe:
    ner = nlp_spacy.get_pipe('ner')


ERROR 7 — ValueError: [E955] Can't find table lexeme_norm
──────────────────────────────────────────────────────────
Cause   : spacy-lookups-data package missing
Solution:
    py -3.11 -m pip install spacy-lookups-data


ERROR 8 — ModuleNotFoundError in Jupyter notebook (packages installed but not found)
──────────────────────────────────────────────────────────────────────────────────────
Cause   : Notebook kernel uses different Python than where packages installed
Solution:
    Step 1: Run in notebook → import sys; print(sys.executable)
    Step 2: Install packages using that exact Python path:
            C:\path\to\python.exe -m pip install pandas numpy matplotlib seaborn


ERROR 9 — Streamlit not found or command not recognized
────────────────────────────────────────────────────────
Cause   : Streamlit installed in different Python version
Solution: Run using full path:
    C:\Users\USERNAME\AppData\Local\Programs\Python\Python311\Scripts\streamlit run app.py
    
Or using py -3.11:
    py -3.11 -m streamlit run app.py


ERROR 10 — SpaCy model not found in Streamlit UI
──────────────────────────────────────────────────
Cause   : Streamlit app not run from inside ner_project folder
          OR Notebook 04 has not been run yet
Solution:
    Step 1: Make sure Notebook 04 ran successfully
    Step 2: Run streamlit from INSIDE ner_project folder:
            cd ner_project
            streamlit run app.py


ERROR 11 — TypeError: float object is not subscriptable (Notebook 05)
──────────────────────────────────────────────────────────────────────
Cause   : metrics.json contains float values (accuracy) alongside dict values
Solution: Add isinstance check when iterating metrics:
    if not isinstance(vals, dict): continue


ERROR 12 — Git remote repository not found
───────────────────────────────────────────
Cause   : Wrong GitHub repository URL added as remote origin
Solution:
    git remote remove origin
    git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
    git push -u origin main


# ── MODEL EVALUATION NOTES ───────────────────────────────────────────────────

Why F1-Score is used instead of Accuracy for NER:
──────────────────────────────────────────────────
In NER datasets, most tokens are non-entities (tagged as O).
A model that predicts nothing would still achieve 90%+ accuracy
just by correctly labeling all non-entity tokens as O.
This makes accuracy a misleading metric for NER tasks.

F1-Score only evaluates actual entity predictions:
  - Precision = correct entities predicted / total entities predicted
  - Recall    = correct entities detected / total actual entities
  - F1-Score  = harmonic mean of Precision and Recall

Our Results:
  SpaCy NER — PERSON F1: 0.678  |  LOCATION F1: 0.804
  CRF       — PERSON F1: 0.727  |  LOCATION F1: 0.836

SpaCy Accuracy (span-level): 60.33%
CRF Accuracy (token-level) : 97.73%

Note: CRF token-level accuracy is high because most tokens are O (non-entity).
      SpaCy span-level accuracy uses strict character matching.
      F1-Score remains the standard and most meaningful metric for NER.
